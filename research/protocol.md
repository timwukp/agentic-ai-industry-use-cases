# PRISM Historical Validation Study — Pre-Registered Protocol

**Status**: FROZEN at git tag `study-preregistered`. Any change to this file,
`chronology.py`, or `cameo_map.py` after that tag invalidates the study's
confirmatory claims. Post-hoc analyses go in the report's clearly-labeled
"Exploratory" appendix.

**Object under test**: PRISM (`tools/finance/quant_batch/prism/`) frozen at
commit `cd565a96bd4c12b51081a8fbcdcf775a3ea2e3d6`, plus the Phase 2 factor
*concept* via reproducible GDELT proxies. The framework is imported as-is;
bugs found mid-study are findings, not patches.

**Seeds**: 7 everywhere (matching PRISM defaults). Bootstrap sizes: TE
n_boot=200 block=20 (PRISM defaults); SPA B=1000 block=20.

---

## 1. Design principles

1. Pre-registration before execution; this document is committed and tagged
   before `run_study.py` exists in runnable form.
2. Point-in-time discipline: any "detection/prediction" claim uses only
   information ≤ t (expanding-window refits via `studylib/pit.py`).
   Full-sample smoothed HMM probabilities support descriptive claims only.
3. Every reported number is generated by committed code with fixed seeds;
   `make study` reproduces the report.
4. Honest nulls are findings. The rubric grades "divergent" as a scientific
   result.
5. Multiple-testing control: BH-FDR within each pre-declared family;
   economic-significance claims face Hansen SPA over the full snooping
   universe.

## 3. Pre-registered hypotheses

All thresholds below are frozen. "Support" requires every listed criterion.

### H1a — Regime layer, descriptive
Smoothed P(stress) from `fit_regimes` (n_states=3) aligns with known stress:
NBER recessions ∪ crash windows (`chronology.py`).
**Statistic**: AUROC of daily P(stress) vs the stress-indicator series.
**Criteria**: AUROC ≥ 0.80 → 支持; 0.65–0.80 → 大體一致; else 分歧.
**Family**: one AUROC per cohort (5), all reported.

### H1b — Regime layer, real-time (point-in-time)
Filtered P(stress) from expanding-window monthly refits (studylib.pit,
min 3y training) detects stress without look-ahead.
**Statistics**: AUROC; median detection lag (business days from stress-window
start to first filtered P(stress) > 0.5).
**Criteria**: AUROC ≥ 0.70 AND median lag ≤ 10bd → 支持; AUROC ≥ 0.70 with
lag > 10bd → 大體一致 (descriptive value only); else 分歧.

### H2 — Causality layer reproduces the literature
`causality_scan` (as shipped: TE + Granger, combined p = max, BH q<0.10)
re-run per era must reproduce `chronology.LITERATURE_EDGES`:
oil→ΔDGS10 significant in moderation era and weaker after 2008; VIX→equity
at h=1 significant in every era ≥1990.
**Criteria**: documented edge significant (q<0.10) in its documented era AND
the era pattern direction matches → 支持; edge found but era pattern absent
→ 大體一致; edge absent where literature finds it → 分歧 (triggers the
pre-registered power audit, §6).

### H3 — Impact functions
VIX shock → equity response: negative, 95% credible band excludes 0 at
h≤5, out-of-sample beats AR(1).
**Statistics**: `local_projection` bands; `walk_forward` fold-pooled losses
compared via Diebold–Mariano (Newey-West HAC, Harvey small-sample
correction).
**Criteria**: band excludes 0 at h≤5 with negative sign AND DM p<0.05 vs
AR(1) → 支持; band excludes 0 but DM n.s. → 大體一致; else 分歧.
**Family**: 2 pre-registered pairs only (oil→DGS10, VIX→NASDAQ); all other
pairs exploratory.

### H4 — Tail calibration (out-of-sample)
Rolling point-in-time 99% VaR (studylib.pit: 5y window GPD refit monthly)
must be calibrated against next-day realized losses.
**Statistics**: violation rate; Kupiec POF; Christoffersen independence and
conditional coverage; Basel traffic-light zone.
**Criteria**: Kupiec p>0.05 AND CC p>0.05 AND green zone → 支持; green zone
with CC rejected (clustered violations) → 大體一致 (triggers
regime-conditional-EVT revision); else 分歧.
**Family**: 2 assets × applicable cohorts, all reported.

### H5 — Factor concept (Track A1, mechanical GDELT proxies, 1979+)
Do GDELT-derived factor proxies (goldstein aggregate) Granger/TE-cause
market variables (NASDAQCOM_ret, DGS10_diff, DCOILWTICO_ret) at any horizon
∈ {1,5,20}?
**Statistic**: `causality_scan` over the full factor×target×horizon grid,
single BH family, q<0.10.
**Criteria**: ≥1 surviving edge that ALSO passes H7 stability → 支持;
edges survive BH but fail stability → 大體一致; clean null → 分歧 from the
Phase 2 premise, reported as a valid finding.
**Coverage caveat (frozen)**: this validates ≤7 mappable factors, NOT the
13-factor taxonomy, and the proxy — not the live Haiku pipeline.

### H5b — Factor event-study (Track B, all factors with ≥3 mapped events)
Factor proxies spike (>2σ vs trailing 250bd) within ±3bd of their mapped
chronology events.
**Statistic**: hit rate; binomial test vs the unconditional base rate of
>2σ days.
**Criteria**: hit rate ≥ 70% AND binomial p<0.05 → 支持; ≥50% → 大體一致;
else 分歧.

### H6 — Economic significance vs data snooping
For every cell in the H2+H5 scanned universe, a naive sign strategy
(position = sign of predicted h-day response; 5bp per side cost) is
evaluated; Hansen SPA (stationary bootstrap, B=1000, block=20) tests the
best performer against the zero-skill null over the ENTIRE universe.
**Criteria**: SPA consistent-p < 0.10 → 支持 (some predictability beyond
snooping); best nominal Sharpe > 0.5 with SPA ≥ 0.10 → 大體一致 labeled
"apparent edge consistent with snooping"; else 分歧 (no economic
predictability — a valid, expected-plausible finding).
**Framing (frozen)**: results are a methodological statement, not
investment advice.

### H7 — Era stability (applies to H2/H5 survivors)
Each surviving edge re-estimated per era (`chronology.ERAS`).
**Statistics**: per-era sign + p; sup-Chow (Quandt-Andrews, 15% trim) on the
LP shock coefficient; ADF/KPSS stationarity table per series per era
(reported descriptively).
**Criteria**: same sign AND p<0.05 in ≥3 of 4 applicable eras → 支持;
sign stable but significance era-dependent → 大體一致; sign flips → 分歧.

### H8 — Tail index stability + jump detection
**Statistics**: GPD ξ per era with bootstrap CIs (500 resamples); AUROC of
bipower RV/BV ratio vs crash-window indicator.
**Criteria**: era CIs pairwise overlap AND jump AUROC ≥ 0.70 → 支持; one
CI disjoint or AUROC 0.6–0.7 → 大體一致; else 分歧.

## 4. Verdict aggregation

The study's headline result is the H1–H8 verdict vector per cohort. No
single blended "accuracy score" will be computed. 支持 / 大體一致 / 分歧
map to the user's 一致 / 大體一致 / 根本分歧 framing.

## 5. Known non-validatable items (frozen scope exclusions)

1. The live Haiku-scored factor pipeline (2 days of history at freeze).
2. Options and single-name equities (not in the data lake).
3. Six sector factors have no pre-2015 proxy (see `cameo_map.UNMAPPABLE`).
4. Pre-1976 daily cross-effects (M-long monthly track only).
5. Stooq gold is a non-official mirror (single-source risk disclosed).

## 6. Pre-registered failure → revision map (executed AFTER the study)

| Observed failure | Triggered revision |
|---|---|
| H4 violations cluster (CC rejects, Kupiec passes) | regime-conditional EVT |
| H4 broad miscalibration | threshold-quantile sweep + refit-frequency change |
| H1b lag > 10bd with strong H1a | regime outputs relabeled "historical context" |
| H3 right-signed but era-unstable | rolling-window LPs or shrinkage sweep |
| H2 misses literature edges | TE binning/lag power audit; quantify max-rule power loss |
| H5 clean null | Phase 2 factors demoted to descriptive context |
| H6 SPA null despite CONFIRMED edges | tighten `confirm()` (add DM gate) |
